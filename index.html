Servidor web
del proyecto

Sitio www.proyecto.local, servido por Apache desde /var/www/proyecto en la red 192.168.10.0/24. Si la ves desde un cliente, la conexión funciona.

Accediste como —
admin@srv-web: ~
admin@srv-web:~$ systemctl status apache2
● apache2.service - The Apache HTTP Server
     Loaded: loaded (/usr/lib/systemd/system/apache2.service)
     Active: active (running)
   Main PID: 812 (apache2)

admin@srv-web:~$ hostname -I
192.168.10.10
admin@srv-web:~$ curl -I www.proyecto.local
HTTP/1.1 200 OK
admin@srv-web:~$
